Capas GPU: cuantas capas del modelo pasan a la placa de video. 0 significa solo CPU. Esto controla memoria VRAM usada, no limita el porcentaje de uso de GPU: con 15 capas la GPU puede marcar 80-100% mientras genera aunque no use toda la VRAM. En este modelo, 1 capa puede rondar 75 MB de VRAM para pesos; 4 capas aprox. 300 MB, 6 capas aprox. 450 MB y 15 capas aprox. 1.1 GB, mas contexto y overhead. Si hay ruido o picos fuertes, baja capas o usa Python con 0 capas.

Contexto: cuanta conversacion puede recordar el modelo en una respuesta. Mas contexto usa mas RAM/VRAM. 4608 suele estar bien; si va pesado, baja a 2048 o 1024.

Hilos CPU: cuantos hilos del procesador usa. Mas hilos puede responder mas rapido, pero deja menos margen para juegos o apps. Si tu CPU tiene 12 hilos, 6 es una mitad razonable.

Ejemplo suave: Capas GPU 4-6, Contexto 4608, Hilos CPU 6. Depende mucho de tu grafica, VRAM, CPU y temperaturas.
